# Library Management System

## About
This is a simple DBMS mini project made using MySQL. It is used to manage student details, book details and book issue records.

## Database Name
LibraryDB

## Tables
1. Students
2. Books
3. Book_Issue

## Operations
- Create database and tables.
- Insert 5 student records.
- Insert 10 book records.
- Insert book issue records.
- Display all students and books.
- Check available books.
- Display student details.
- View issued books using JOIN.
- Count books by category using GROUP BY.
- Count total students.
- Update student department.
- Return a book and update its status.
- Delete a student (example query).

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- UPDATE
- DELETE
- JOIN
- GROUP BY
- COUNT
- PRIMARY KEY
- FOREIGN KEY

## Sample Data
- 5 Students
- 10 Books
- 4 Book Issue Records

MySQL
